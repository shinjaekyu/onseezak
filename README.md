# 오늘시작 공홈(onseezak.com) 작업 도구와 방법

2026-11-16에 처음 만든 제작 파일(/home/claude/site, guide_render.py, build.py)이 작업 환경 교체로 없어졌습니다.
그 뒤로는 **main 브랜치의 완성된 HTML이 원본**입니다. 이 브랜치(source-tools)는 그 HTML을 고칠 때 쓰는 도구와 규칙을 보관합니다.
이 브랜치는 공홈에 게시되지 않습니다(GitHub Pages는 main만 사용).

## 파일
- `faq_add.py` — FAQ 문항 추가. 번호, 문항 수, 목록, 검색엔진용 데이터, 날짜를 한 번에 고칩니다.
- `guide_add.py` — 부위별 가이드 글 추가. 글 내용을 JSON 파일로 주면 페이지를 만들고 목록·모음·sitemap·llms.txt·rss.xml을 함께 고칩니다. `upper-body.json`이 예시입니다.
- `photo_bg.py` — 모델 사진의 배경만 공홈 스튜디오 색(#F4F2F0)으로 바꾸고 3:4(900x1200)로 맞춥니다. 인물과 제품은 건드리지 않습니다. `python3 photo_bg.py 원본.png 결과.webp`
- `photo_tone.py` — 변형 제품 사진의 원단 색조만 기준 사진에 맞춥니다(피부·배경은 그대로). 대표 요청이 있을 때만 씁니다. `python3 photo_tone.py 기준.webp 대상1.webp 대상2.webp`
- `photo/model_cut_build.py` — 모델 컷 정리(피부 색조 맞춤 → EDSR 2배 화질 복원 → 스튜디오 배경·그림자 → 1350x1800/900x1200/썸네일). EDSR_x2.pb 모델 파일은 Saafke/EDSR_Tensorflow 저장소에서 내려받아 model/ 폴더에 둡니다. ST374에 사용(2026-11-19).
- `qa.js` — 배포 전 점검(320·375·1280px 넘침, H1 1개, JSON-LD).

## 작업 순서
1. `git pull` 후 main의 HTML을 고칩니다. 같은 문장이 meta·og·JSON-LD에 반복되면 모두 함께 바꿉니다.
2. `python3 -m http.server 8765 &` → `node qa.js <주소들>`로 점검합니다.
3. 바뀐 내용을 대표에게 보여 주고 "올려"를 받은 뒤에만 commit·push 합니다. (단순 사진 교체·삭제 요청은 바로 반영)
4. HTML을 직접 고치면 검색엔진 자동 알림(IndexNow)이 가지 않습니다. 네이버 서치어드바이저와 구글 서치콘솔 수집 요청 주소를 대표에게 알려 줍니다.

## 지켜야 할 규칙
- 금지 표현: 치료·예방·붓기 개선·완화·회복 촉진·효과 보장·최고·1등·100%·완벽·의료용, 의료진 협업 암시, 병원 이름, 경쟁 업체 이름, FAQ 안의 금액.
- 용어: 사이즈(치수 X), 붓기(부기 X), 사이즈 측정(체촌 X). 압박복은 일반 의류.
- 공개 금지: 원단 공급사 코드, 납품 단가, 화장품 원가.
- 사진: 동의 받은 실제 착용 사진만. 피 얼룩·문신·개인 소지품은 모자이크. 체형·제품 모양 변경 금지. 대표 사진은 모델 사진 유지.
- 일본어 페이지: 줄바꿈은 `<wbr>` 위치에서만 일어납니다(문절 단위). 단어 중간에 `<wbr>`을 넣지 않습니다. 전화번호·우편번호·시간은 `class="keep-line"`.
- 상세 기록은 claude.ai 프로젝트 문서(배포-운영-메모, 네이버-연관검색어-추적, 닥터나우-추적 등)에 있습니다.
